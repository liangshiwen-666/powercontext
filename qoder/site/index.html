为什么做它

复习最难的不是「再看一遍」，是知道自己漏了什么

大多数笔记工具只解决存储和搜索。知返多做一步：把「没懂」变成一个可追踪、可召回的对象，再让复习计划围着它转。

资料散落，找不到原话

笔记、讲义、PDF 各在一处。知返统一入库并按标题 / 页切块，回答必须带文档、章节与 chunk_id，资料里没有就直说没有。

学过就忘，下次从零开始

「没懂页面置换」一旦写进记忆，下次提问会被自动召回，复习计划会把它排进去——不需要你重新描述一遍背景。

计划拍脑袋，复习没重点

计划只从记忆里的薄弱点与进度生成，不随机抽题；每个安排都附上引用的 artifact_id@revision，可逐条核对。

技术分工

两种技术各管一件事，都在主流程里

不是安装完就闲置的组件：每一条回答、每一次「标记没懂」都会实际读写这两套存储，并且可以在接口与页面上对照。

seekdb

资料在哪

  • 笔记切块写入 collection materials_384，384 维向量，HNSW / cosine。
  • 每次提问同时走向量通道与全文通道（$contains），客户端 RRF 融合。
  • 返回片段带文档、章节、页码、chunk_id 与分数，直接成为回答引用。
可核对 GET /api/health → seekdb GET /api/evidence → hit_ids / score / latency
PowerContext

我学到哪

  • 每个用户一个 Scope（study-coach:<user_key>），薄弱点是独立原子记忆。
  • 写入返回 artifact_id@revision；下一次提问由 /v1/memory/search 召回并注入回答。
  • 复习计划读取同一批 artifact，页面上逐条展示引用来源。
可核对 GET /api/memories → artifact_id / revision GET /api/plan → weak_points[].artifact_id

安装与运行

两条路径都已实测

Windows 用 Docker 跑 seekdb 远程模式；WSL / Linux 用 seekdb 嵌入式模式，不需要 Docker。首次运行会下载约 86 MB 的本地嵌入模型。

Python 3.12 PowerContext 1.4.1 pyseekdb 1.4.0.post1 seekdb Docker 镜像 FastAPI 0.162

  1. 准备工具

    python -m pip install --user uv
uv tool install "powercontext[cli,server]==1.4.1"
cd qoder
uv sync --python 3.12
cp .env.example .env

  2. 启动 seekdb 并建库

    docker run -d --name seekdb -p 2881:2881 -p 2886:2886 oceanbase/seekdb:latest
docker exec seekdb mysql -h127.0.0.1 -P2881 -uroot \
  -e "CREATE DATABASE IF NOT EXISTS study_coach;"

    拉取 Docker Hub 失败时可用镜像：docker.m.daocloud.io/oceanbase/seekdb:latest，再 docker tag 成本地 oceanbase/seekdb:latest。

  3. 改 .env 并启动

    # SEEKDB_MODE=remote
# SEEKDB_HOST=127.0.0.1   SEEKDB_PORT=2881
# SEEKDB_USER=root        SEEKDB_DATABASE=study_coach
# HF_ENDPOINT=https://hf-mirror.com

powershell -ExecutionPolicy Bypass -File scripts\start.ps1

    应用 http://127.0.0.1:8080；PowerContext http://127.0.0.1:8000（Dashboard /dashboard/）。

边界与安全

如实说明能力边界

本机演示，不上传云端

笔记、记忆与日志只存本机（seekdb / PowerContext SQLite / data/app.db）。网站只展示项目，不在服务器上运行后端。

没有 Key 时的降级

未配置模型时回答为模板整理，计划为规则生成；/v1/context/prepare 如实返回 empty，不伪造语义能力。

本地向量模型的中文短板

all-MiniLM-L6-v2 中文语义排序偏弱，用全文通道与关键词覆盖加权补偿；配置 API 向量可进一步提升。

仓库只保留 .env.example 占位值；.env、虚拟环境与本地数据目录均在 .gitignore 中。PowerContext 默认仅绑定 127.0.0.1、访问控制为 disabled，暴露公网前必须开启鉴权并更换示例凭据。
