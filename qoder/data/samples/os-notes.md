# 操作系统 · 复习提纲

## 进程与线程

进程是资源分配的基本单位，线程是 CPU 调度的基本单位。同一进程内的线程共享地址空间、打开的文件和信号处理，但每个线程有独立的栈和寄存器上下文。线程切换比进程切换开销小，因为不需要切换页表。

## 调度算法

常见调度算法包括先来先服务（FCFS）、短作业优先（SJF）、时间片轮转（RR）、多级反馈队列（MLFQ）。SJF 的平均等待时间最优，但可能导致长作业饥饿。MLFQ 通过动态调整优先级兼顾响应时间和吞吐量，是通用操作系统的常用选择。

周转时间 = 完成时间 − 到达时间；带权周转时间 = 周转时间 / 服务时间。

## 虚拟内存与页面置换

虚拟内存让每个进程拥有独立的地址空间，通过页表把虚拟页映射到物理页框。缺页中断发生时，若物理内存已满，需要按页面置换算法选择一个页面换出。

FIFO 可能出现 Belady 异常（增加页框反而缺页更多）。LRU 理论效果好但实现成本高，实际系统常用 Clock 算法近似 LRU。工作集模型用来描述进程在一段时间内实际访问的页面集合，是防止抖动的关键概念。

## 死锁的四个必要条件

互斥、请求并保持、不可剥夺、循环等待。四个条件同时满足才可能发生死锁，因此预防策略就是破坏其中任意一个。银行家算法属于死锁避免，它在分配前判断系统是否仍处于安全状态。
