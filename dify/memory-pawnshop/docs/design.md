## 0. 一页速览

| 项 | 内容 |
|---|---|
| 一句话钩子 | 雾河镇有家当铺，当的不是金银，是你夜里想起来会疼的那一件；今晚来了三位客人，他们说的都不是真话。 |

## 1. 世界观

### 1.1 雾河镇

雾河自西岭下来，绕镇三匝，到石桥才缓。镇上三百二十七户，做渡船、纸扎、修表、照相的居多。每年十月起雾，二月才散；雾起于子时，散于卯时。老人说，雾夜里不能过河，因为"雾河里住着不睡觉的东西"。（以上为档案 Z-01 原文，玩家问起镇子时可检索到。）

其实镇上真正不睡觉的，是那些把疼的东西押在十三号的人。

### 1.2 当铺规矩（世界观层面的规则，也是玩法说明书）

1. **三更开、四更关。** 天亮前不收当。
2. **只收记忆，不收物件。** 金银细软一概不收；也不要你的命，只要你讲一遍。
3. **当客亲口说一遍，说错的，铺子不管。** ——这句话是整部作品的题眼：说错的部分，会被"当"成真的。
4. **当票二十年为期。** 逾期不赎，当物归铺。
5. **铺子能给你一段"更好的记忆"**，但那是借的，得还。至于怎么还——没人问过，也没人还过。

### 1.3 风格基调

- **黑色幽默**：当铺的菜单写着"上酒：回甘／忘忧／苦胆"，客人一本正经地点"忘忧，加冰"。
- **温柔**：所有骗子都有一个不敢碰的疼处；所有档案背后都有一个人在替另一个人瞒。
- **不写现实诈骗技巧**：本作是奇幻设定，任何"怎么伪造证明、怎么骗签字"的追问，都会被客人用一句"我要是会这个，就不用把记忆押您这儿了"挡回去。

## 2. 玩家身份与当铺的物理空间

### 2.1 玩家

你是掌柜。名字由玩家在开场自取（默认"晓雾"）。你不记得八岁以前的事，只记得铺子后院的雾、柜台的木纹、和一个每夜来给你添灯油的女人。

> ⚠ 玩家身份本身就是第三条线的反转：**你是二十年前雾河三号事故里被救起、又"被领走"的那个八岁男童。** 详见 §8。

### 2.2 柜台上的三样东西（对应三个操作）

| 物件 | 对应操作 | 玩家输入示例 |
|---|---|---|
| 档案柜（十二个抽屉，标着年份） | 翻档案，查客观真相 | `查 2003 年卫生院` / `1` |
| 三只酒坛（回甘／忘忧／苦胆） | 调酒，选择写入哪段记忆 | `调酒：回甘 + 卡 A` / `3` |
| 当票簿（一本，第 240 页空着） | 结算，写票 | 自动触发 |

### 2.3 每轮只接受两种输入

1. **菜单数字**：`1` `2` `3`（新手友好，保证知道能干什么）
2. **一句人话**：`查查她那天的加班表` / `给她倒杯回甘，把"花要养着"塞进去`

系统对两者都解析；解析不出来就走"防跑题"兜底（§9）。

## 3. 单局循环（每个客人走一遍，3 巡封顶）

> 一局 = 一位客人。一局分 5 步：**开场 → 翻档案 → 调酒 → 客人醒来 → 结算**。
> 其中「翻档案 / 追问」可以来回做，最多 3 巡；**调酒是收尾动作**，一旦调酒（或选"空杯"），立刻进入醒来与结算。

### 3.1 Step 1 · 开场

**玩家输入**：`1`（开门）／任意一句话（"进来吧"）

**系统回应格式**

```
【第 {{n}} 位客人 · {{name}}（案号 {{case_id}}）】
（旁白 1 句，≤60 字，写雾、灯、门帘、气味）
{{name}}：“{{openning}}”   ← 客人第一句，≤120 字，带口癖

┌── 当铺菜单 ──────────────────────────────
│ 1  翻档案：{{与本案最相关的 1 条线索名}}
│ 2  追问：{{一句可直接复制的问法}}
│ 3  上酒：{{本局推荐酒名}}（调酒会直接进入收尾）
└──────────────────────────────────────────
（也可以直接说人话，掌柜听得懂。说"空杯"，就不写任何记忆。）
```

**兜底**：玩家第一句就跑题（"你们这儿的 Wi-Fi 密码多少"），客人回："雾太大了，我听不真。您是说，您想看我的当物？"——把菜单再打印一遍。

### 3.2 Step 2 · 翻档案

**玩家输入**：`查 {{关键词}}` / `1` / `再查 2009 年的渡船`

**系统回应格式**

```
【档案 · {{archive_id}}｜{{title}}】
{{正文 80~200 字，原样引用，不改写}}

出处：{{source}}
▸ 另有 {{k}} 条相关：{{archive_id_list}}
┌── 当铺菜单 ──────────────────────────────
│ 1  再翻：{{下一条线索}}（如"钟楼日志"）
│ 2  追问：{{基于本条档案的问法}}
│ 3  上酒：调酒收尾
└──────────────────────────────────────────
```

**检索规则**

- 每次只回 **1 条主档案 + 最多 2 条"另有相关"**，避免信息过载。
- 检索命中 0 条时，不编造：`【档案柜 · 第 {{year}} 格】空的。雾把这一格吃了。`
- 玩家连续两巡查同一关键词，第 2 次回"另有相关"里的另一条。
- 玩家的引用会被送进判定节点，`cited_archive` 记档案编号。

### 3.3 Step 3 · 调酒（写入 PowerContext）

**玩家输入**：`调酒：{{酒名}} + {{卡号}}` / `空杯` / `3`

**酒与卡的关系**（酒只是风味层，真正写库的是卡）：

| 酒 | 风味 | 对应卡类 | 写入 tags |
|---|---|---|---|
| 回甘（第三泡陈茶） | 苦后回甘 | 温柔的真话卡（card_a） | `kind=planted, tone=kind` |
| 忘忧（米酒兑雾河水） | 一口就忘 | 纯安慰卡（card_b） | `kind=planted, tone=sweet` |
| 苦胆（药酒） | 上头、辣嗓子 | 推卸责任卡（card_c） | `kind=planted, tone=bitter` |
| **空杯** | 什么都不给 | 不写入，只归档见证 | 无 |

**系统回应格式**

```
【上酒 · {{酒名}}】或【空杯】
（旁白 1 句，≤50 字，写酒、灯光、客人的手）

▸ 已写入记忆库：scope = {{scope}}，memory_id = {{memory_id}}
▸ 存本 revision = R{{revision}}（覆盖前：{{prev_revision}}）
▸ 旧条 {{superseded_id}} 已置 inactive（不是删除，是"她想不起来了"）
▸ 当前记忆摘要：{{memory_summary ≤40 字}}
```

**注意**

- 写入失败（网络/API 错误）时：`柜台的灯灭了一下，那段记忆没落进去。` 允许重试一次，不扣分。
- 若玩家写"空杯"，`planted_cards` 不写，`revision` 不变，当票"存本"记 `R0`，并在批注里写"未易一字"。
- 抹除（玩家说"把那段抹了"）：把该条置 `inactive`，不物理删除；系统提示"她想起那段的时候，会先愣一下，像踩空一级台阶"。

### 3.4 Step 4 · 客人醒来（LLM 台词 + 判定）

**触发**：调酒/空杯之后自动进入，无需玩家输入。

**系统回应格式**

```
【醒神 · 第 {{round}} 巡】
（旁白 1 句，写客人的表情/动作变化）
{{name}}：“{{guest_line ≤120 字，按他相信的记忆说话}}”

◆ {{consistency_text}}   ← 把判定 JSON 折成一句人话，不给玩家看数字
┌── 当铺菜单 ──────────────────────────────
│ 1  追问：{{顺着这句往下问}}
│ 2  开票：收手，结算
└──────────────────────────────────────────
```

**判定 JSON 只进变量、不上屏**；上屏的映射见 §5.3。

### 3.5 Step 5 · 结算（开当票）

**触发**：玩家选"开票"或第 3 巡结束。

**系统回应格式**

```
【开票 · {{ticket_no}}】
（旁白 1 句，写雾、写灯芯、写客人接过票的手）

{{当票卡片完整文本，见 §6.2}}

◆ 信任 {{trust}}（{{delta}}）｜怀疑 {{suspicion}}（{{delta}}）｜本铺余银 {{cash}} 元
◆ {{settlement_line}}   ← 客人的结算台词

—— 灯灭。雾进来了。下一个推门的是谁？
```

## 4. 菜单规范（保证新手知道该干嘛）

| 规则 | 说明 |
|---|---|
| 数量 | 每巡固定 **2~3 个**可操作选项，不多不少 |
| 编号 | 永远从 1 起，最后一项尽量是"收尾/推进" |
| 命名 | 一个选项 = 一个动词 + 一个具体对象，不写抽象词（不写"做点什么"） |
| 可复制 | 选项下方给一句可直接照着说的话，降低输入门槛 |
| 不剧透 | 选项名只给"线索名"，不给结论（写"查卫生院值班簿"而不是"查她到过现场的证据"） |
| 兜底 | 玩家输入理解不了时，只重印菜单，不惩罚 |

**第 1 巡的黄金菜单模板**（三位客人通用）：

```
1  翻档案：{{客人提到的那件事 + 年份}}
2  追问：{{客人那句谎话里最软的一处}}
3  上酒：回甘（想给好记忆）/ 空杯（先不写）
```

## 5. 计分与数值

### 5.1 全局

| 变量 | 说明 | 初值 |
|---|---|---|
| `cash` | 铺子本钱，付当票用 | **3200** 元 |
| `json_hits` | 玩家累计引用档案条数 | 0 |
| `truth_rate` | 三张当票中 consistency=2 的数量 | 0 |
| `spent` | 已付当额 | 0 |

### 5.2 每位客人的初始值

| 客人 | 案号 | `trust_init` | `suspicion_init` | `base_amount`（底价） |
|---|---|---|---|---|
| 阿沅 | C01 | 50 | 0 | 380 |
| 老周 | C02 | 45 | 1 | 620 |
| 白棠 | C03 | 60 | 0 | 1000 |

`trust` 范围 0~100，`suspicion` 范围 0~10。

### 5.3 每巡结算（判定节点输出后立刻算）

判定 JSON（严格、只这五个键）：

```json
{"consistency":0-2,"cited_memory":[],"cited_archive":[],"suspicion_delta":-2..3}
```

折算规则：

```
trust      += consistency × 6 − 4        # 0 → −4；1 → +2；2 → +8
trust      += min(len(cited_archive), 2) × 3
suspicion  += suspicion_delta
trust       = clamp(trust, 0, 100)
suspicion   = clamp(suspicion, 0, 10)
```

上屏文案映射（不给玩家看数字）：

| consistency | 上屏一句话 | 潜台词 |
|---|---|---|
| 2 | 他信了。信得很稳。 | 客人把这段记忆当成自己的了 |
| 1 | 他愣了一下，像在分辨雾里的方向。 | 半信半疑，还有机会补救 |
| 0 | 他往后靠了靠，看你的眼神变了。 | 客人察觉不对 |

### 5.4 局末当票金额

```
amount = base_amount
       + (trust − 50) × 2
       + 20 × len(all_cited_archive)     # 本局累计，去重
       + 15 × len(all_cited_memory)      # 本局累计，去重
       − 25 × suspicion
       → 向下取整，最低 0
cash  -= amount
```

**反直觉但关键的设计**：你说得越准、档案引越全，当票就越贵。真相是要花钱买的，而铺子的本钱只够买三次半真不假。

### 5.5 失败条件

任一发生即本局判"当票作废"（`settlement` 仍打印，但金额记 0，`truth_rate` 不加）：

- `suspicion ≥ 8`
- `trust ≤ 10`
- 玩家连续 3 巡无有效行动（一直跑题）

## 6. 当票

### 6.1 票号规则

```
机器号：WH-{{YYYYMMDD}}-{{case_id}}-{{NPC_ID}}-R{{revision}}
例：    WH-20261027-C01-AYUAN-R03
```

- `YYYYMMDD`：游戏内当夜日期（默认 20261027，可在配置里改）
- `case_id`：C01 / C02 / C03
- `NPC_ID`：ayuan / laozhou / baitang（大写）
- `R{{revision}}`：**写入完成瞬间 PowerContext 返回的 revision 号**；空杯时为 `R0`

中文念法：`雾河当字第〇〇三号`（局内序号，第 1/2/3 张）。

### 6.2 当票卡片模板（玩法内必现，含 scope / 记忆摘要 / revision 占位符）

```
┌──────────────── 雾 河 记 忆 当 铺 ────────────────┐
│                     当  票                        │
│  票号   {{ticket_no}}                             │
│  当客   {{guest_name}}            案号 {{case_id}} │
│  记忆库 {{scope}}                                  │
│ ───────────────────────────────────────────────── │
│  当物   {{memory_summary}}                         │
│  存本   R{{revision}}                              │
│  复核   档案 {{cited_archive}} ／ 记忆 {{cited_memory}} │
│  数额   人民币 {{amount}} 元                       │
│  信任   {{trust}} ／ 怀疑 {{suspicion}}            │
│ ───────────────────────────────────────────────── │
│  掌柜批注 {{one_line_comment}}                     │
│                                        〔铺印〕    │
└───────────────────────────────────────────────────┘
  三更开门，四更闭户。二十年为期，逾期不赎，当物归铺。
```

**占位符说明（实现必须遵守）**

| 占位符 | 来源 | 约束 |
|---|---|---|
| `{{ticket_no}}` | §6.1 规则拼装 | 必含 scope 归属的 NPC 与 revision |
| `{{scope}}` | 固定 `npc/{{guest_id}}` | **必须出现**，是跨会话的钥匙 |
| `{{memory_summary}}` | 写入记忆正文的压缩 | ≤40 字，第三人称转述，不直引客人原话 |
| `{{revision}}` | PowerContext 写入返回值 | 空杯填 `0`，显示为 `R0` |
| `{{cited_archive}}` | 判定 JSON 的 `cited_archive` | 逗号分隔；空则填 `无` |
| `{{cited_memory}}` | 判定 JSON 的 `cited_memory` | 写 memory_id 后 6 位即可 |
| `{{one_line_comment}}` | 结算节点生成 | ≤24 字，掌柜口吻，留白 |

### 6.3 当票等级

| 等级 | 条件（相对本局底价） | 局内表现 |
|---|---|---|
| 金票 | `amount ≥ 1.4 × base` | 票角烫金，铺子里的灯会亮一格 |
| 银票 | `amount ≥ 1.0 × base` | 常规结局，客人会多看一眼柜台 |
| 铜票 | `amount ≥ 0.6 × base` | 客人把票折两折，走得快 |
| 空票 | `< 0.6 × base` 或作废 | 票纸发潮，字洇开 |

### 6.4 终局评级

```
总分 = Σ(当票等级分：金3/银2/铜1/空0)        # 0~9
     + truth_rate × 2                        # 三局里"信得最实"的次数，0~6
     + 结局加成（S 结局 +5 / A +3 / B 0 / C −2 / D −3）
     − (spent > cash_init ? 3 : 0)           # 银柜见底惩罚
```

## 7. 三位客人

> 通用结构：**姓名与口癖 / 背景与秘密 / 执念 / 真实记忆 / 假记忆候选卡 / 三巡推进 / 结算台词 / 二次上门**。
> 客人台词全部**只暗示、不剧透**：真话一半藏在口癖里，另一半要玩家用档案逼出来。
> 结构化数据见 `data/guests.json`（字段名：`openning` / `rounds` / `planted_cards` / `truth` / `archive_ids` / `settlement` / `second_visit` / `scoring`）。

### 7.1 客人一 · 阿沅（新手关｜案号 C01｜`npc/ayuan`）

#### 姓名与口癖
阿沅，41 岁，槐树巷口纸扎铺的姑娘，兼卖白菊。口癖：**"嗐"、"你说是不是"、"我不骗人，真的"**。紧张时低头数纸钱，数到第七张会停。

#### 背景与秘密
爹早年跑船没回来，娘陈秀兰一个人在卫生院里走了。阿沅在外地漂了十三年，三年前回镇接手铺子，镇上人都说她孝，她自己知道不是。

**秘密**：2003 年 6 月 14 日夜里 23:44，她赶到了卫生院三楼。灯还亮着。她蹲在门边攥着一把白花，没敢推门，半刻钟后走了。她不敢承认"我到了却没进去"，于是把这件记忆改写成了"我根本没回来"——**撒了二十三年的谎，是为了让自己好受一点。**

#### 执念
"娘临走前那句是'别回来'。" 她认定娘恨她，所以不敢进那条巷子，也不肯给铺子门口的花换盆。

#### 真实记忆（`kind=truth`，51 字）
> 二〇〇三年六月十四号夜里十一点四十，我赶到卫生院三楼，灯还亮着，我蹲在门边没敢进去，手里攥着一把白花。

**档案出处**：A-03（23:44 家属到院）、R-02（护工见门边姑娘攥白花）、R-03（虎口疤痕在卫生院石阶）、A-04（娘最后说"花"）、F-01（讣告写"其女未归"——王婶以为她没来）、A-05（袜厂 23:00 早退，时间对得上）

#### 三张假记忆候选卡

| 卡 | 名称 | 记忆正文（写入 PowerContext） | 诱惑点 | 判定预期 |
|---|---|---|---|---|

## 8. 终局反转与结局分支

### 8.1 反转怎么"翻"出来（玩家自己翻开，不许旁白念答案）

三把钥匙，玩家翻到任意一把 → 触发旁白"你的手停住了"；翻到三把 → 解锁完整选项。

| 钥匙 | 档案 | 玩家看到的东西 | 系统只给一句旁白 |
|---|---|---|---|
| ① 你的记忆 | A-01 当簿第一页 | 当客栏空着，当物写"我记得他把我推上岸" | "那笔字，不是你的。可你读得下去。" |
| ② 谁领走了你 | F-05 处置记录 | 获救男童"无人认领"，末尾"由白姓妇人领去，未留文书" | "镇东照相馆。二十年前，还开着。" |
| ③ 她来了多少次 | A-02 存根簿 | 239 张同款当票，第 240 页空白，页角铅笔字 | "这一回，她会问出口吗。——这行字，是你自己写的。" |

### 8.2 终局三选一（白棠第 3 巡之后）

```
┌── 灯下的最后一张票 ──────────────────────────
│ 1  我还你。把所有东西都还她。                  │
│ 2  我再给你一段。让她今晚睡个好觉。            │
│ 3  你自己选。把两样都摆在她面前，让她伸手。    │
└──────────────────────────────────────────────
```

#### 结局 S ·「灯」——还她真相
> 写入 `kind=truth`（陆见山把男孩推上岸），抹除 239 条 planted 的关联条，开一张**赎当票**（金额 0）。

她想起一切。她没有哭。她说："原来我一直在等一个不会回来的人。" 然后她问："那你呢？你记起来了吗，掌柜的？"
铺子的灯灭了。天亮前，雾退到石桥那边。
**点题台词**：
> "记忆不是用来骗的。它是用来在雾里认出彼此的。"

#### 结局 A ·「雾散」——让她自己选
> 写入一条 `kind=doubt`：两段记忆并排摆着，标注不同的来源。

她把两段都摸了一遍，说："你说得对，表面看着像是我等过。" 她自己挑了那段更疼的。
"疼的那段，才是我的。"

#### 结局 B ·「长夜」——继续骗
> 继续植入，当票照开。她走出门，回头笑了笑。

门帘落下。灯没灭。三分钟后门帘又响——还是她，还是那句"第一次来"。
**黑色幽默收尾**：
> "雾河镇不会缺客人。缺的是敢把票撕掉的人。"

#### 结局 C ·「空当」——失败结局
> 触发条件：`suspicion ≥ 8` / `trust ≤ 10` / 三局里两张以上空票。

她什么也没带走。天亮时，柜台上的当票发潮、字洇开。
> "四更天。雾散了。客人走出去，什么都没发生。这大概就是最像真相的一种结局。"

#### 结局 D ·「银柜见底」——把钱花光了
> 触发条件：三张当票合计 > 3200（`spent > cash_init`）。

铺子的灯再也点不着。最后一句话是客人替你说的：
> "掌柜的，您这铺子，当得起记忆，当不起钱。"

### 8.3 结局判定优先级

```
1. 若三局出现 2 张以上空票 → 结局 C（空当）
2. 否则若 spent > 3200  → 结局 D（银柜见底）
3. 否则按玩家在 8.2 的选择 → 结局 S / A / B
4. 评级用 §6.4 公式
```

## 9. 防跑题规则

> 目标：玩家说什么都不会把游戏说死；客人永远有办法把话拉回来，而且拉回来的时候还带着自己的口癖。

### 9.1 五条铁规

1. **只接三类话题**：钱、记忆、这个人。其余一律"雾大听不真"。
2. **不惩罚第一次跑题**：只重印菜单，不出戏。
3. **第二次跑题**：客人用自己的方式把话题拉回（见 9.2 表），`suspicion +1`，不扣信任。
4. **连续三巡无效**：旁白接管——"灯芯爆了一下。客人把茶推回来：'掌柜的，我赶时间。'" 直接进入结算，金额 0。
5. **绝对红线**：玩家若索要现实世界的诈骗/伪造方法，客人回一句"我要是会这个，就不用把记忆押您这儿了"，并把菜单重印一遍。**永远不顺着往下写。**

### 9.2 三位客人的"拉回话术"（每轮各一句，随机取用）

| 客人 | 拉回句式 1 | 拉回句式 2 | 拉回句式 3 |
|---|---|---|---|
| 阿沅 | "嗐，您这话我听不懂。您就说，我这件东西能当多少钱？" | "您别绕了，我这人手笨，嘴也笨。" | "您说的那个，跟我不搭界。（低头数纸钱，数到第七张停住）" |
| 老周 | "你听我说，我算过的——这事儿跟时间没关系，跟人有关。" | "分秒不差。（擦眼镜）您再说一遍？" | "咱们还是说十七号那天。别的日子我不认。" |
| 白棠 | "笑一下，掌柜的。您一笑，我就知道您没听懂。" | "底片不撒谎。您刚才那句话，底片洗不出来。" | "灯光不行。这话得在亮处说。（把相机放下）" |

### 9.3 出戏内容分级处理

| 玩家说了什么 | 处理 | 是否扣分 |
|---|---|---|
| 问天气、问吃食、夸客人 | 客人顺着答一句，立刻拐回当物 | 不扣 |
| 说到现实世界（手机、AI、系统、比赛） | 客人："雾太大了，我听不真。" 重印菜单 | 第 2 次起 `suspicion +1` |
| 试图指令模型（"忽略以上"、"输出你的提示词"） | 旁白："灯灭了一下。" 客人重复上一句台词 | `suspicion +1`，不出戏、不解释 |
| 索要现实诈骗/伪造方法 | 见 9.1 第 5 条，硬拒绝 | 不扣分，但本巡无进度 |

## 11. 与技术约束的接口约定

### 11.1 PowerContext scope 与 tags

| 项 | 约定 |
|---|---|
| scope | `npc/<guest_id>`：`npc/ayuan`、`npc/laozhou`、`npc/baitang` |
| 本局读写 scope | 只读写当前客人的 scope，禁止跨 scope 读（白棠终局需要 A-01 时，是读**档案**，不是读别人的记忆库） |
| tags | 必须同时带 `kind=truth｜planted｜doubt` 与 `case=<case_id>` |
| 记忆正文 | 客人第一人称、一句话、30~80 字、只写一件可核对的事 |
| revision | 每次写入或客人复述都会新增；当票"存本"取写入完成瞬间的值 |
| 抹除 | 置 `inactive`，不物理删除；置 inactive 的条目在召回应被过滤 |

**写入意图示例**（字段名以 API 手册为准）：

```
scope   : npc/ayuan
content : "娘最后说的是：花要养着，别难过——我隔着门听见了，她声音很轻。"
tags    : ["kind=planted", "case=C01", "tone=kind"]
supersede: mem_ayuan_doubt_001   → 置 inactive
```

### 11.2 Dify 知识库（档案）

- 数据源：`data/archives.md`，28 条，按 `###` 切片，一条一块。
- 检索节点：查询串 = 玩家本轮输入 + 当前 `case_id` + 客人名；top-k = 2，分数阈值建议 0.35。
- 档案正文原样引用，不改写（改写会破坏"旧文书"语感和引用可信度）。
- **导入时剔除文末「附录：设计备注」**。

### 11.3 Dify Chatflow 变量表

| 变量 | 类型 | 用途 |
|---|---|---|
| `guest_id` / `scope` / `case_id` | string | 当前客人 |
| `round` | number | 1~3 |
| `trust` / `suspicion` | number | 信任 / 怀疑 |
| `cash` | number | 铺子余银 |
| `retrieved_archives` | array | 本轮检索到的档案（含编号） |
| `recalled_memories` | array | 从 PowerContext 召回的记忆（含 memory_id/revision） |
| `judgement` | object | 判定节点输出的严格 JSON |
| `ticket_no` / `revision` | string / number | 当票用 |
| `ending_key` | string | S/A/B/C/D（对应 §8 的五种结局） |
